# VPN Attack Payloads

## VPN Fingerprinting and Detection

### IKE Scanning (IPSec VPN)
ike-scan 192.168.1.0/24                                                # Scan for IPSec VPNs
ike-scan -M 192.168.1.100                                              # Aggressive mode scan
ike-scan -A 192.168.1.100                                              # Main mode scan
ike-scan -M -A --id=test 192.168.1.100                                 # With group name
ike-scan --sport=500 --dport=500 192.168.1.100                         # Specific ports
ike-scan -M --trans=5,2,1,2 192.168.1.100                              # Custom transform

### Nmap VPN Detection
nmap -sU -p 500,4500 --script=ike-version 192.168.1.100                # IKE version detection
nmap -sU -p 500 --script=ipsec-ike-info 192.168.1.100                  # IPSec info
nmap -p 1194 --script=openvpn-info 192.168.1.100                       # OpenVPN detection
nmap -p 1723 --script=pptp-version 192.168.1.100                       # PPTP detection
nmap -sU -p 1701 192.168.1.100                                         # L2TP detection

### SSL VPN Detection
nmap -p 443 --script=ssl-cert 192.168.1.100                            # SSL certificate
nmap -p 443,4433,8443 --script=http-title 192.168.1.100                # Web-based VPN
sslscan 192.168.1.100:443                                              # SSL/TLS analysis

### VPN Service Banners
nc -v 192.168.1.100 1723                                               # PPTP banner
curl -I https://192.168.1.100                                          # HTTPS VPN portal
