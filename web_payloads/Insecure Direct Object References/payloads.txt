## ========================================

- IDs in URLs, parameters, body, headers

# 2. Test sequential access
- Increment/decrement IDs
- Try common IDs (0, 1, 100, admin)

# 3. Test unauthorized access
- Access other users' resources
- Try administrative functions

# 4. Test different methods
- GET, POST, PUT, DELETE, PATCH

# 5. Test parameter manipulation
- Change IDs, types, roles
